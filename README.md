# vi練習道場

**▶ 今すぐ練習する：https://ohtsuka-shota-se.github.io/vi-practice-dojo/**

ブラウザで動く vi の練習機です。インストール不要で、上のリンクを開けばすぐに始められます。
何を打っても実際のサーバーには影響しないので、安心して失敗しながら覚えられます。

## できること

- シェルで `vi ファイル名` と打ってファイルを開くところから、本物と同じ流れで練習できます
- 40のミッションを、易しいものから順にクリアしていきます
  - 基本（開く・閉じる・保存）／移動／削除／入力／書き換え／コピー／検索・置換／取り消し／シェル連携（EDITOR・crontab）／総合問題／キー数チャレンジ
- 今のモード（NORMAL／INSERT／COMMAND）が色で表示されるので、迷子になりません
- `E37` や `E486` など、エラーメッセージも本物の Vim と同じ文言で表示されます
- 自由練習モードでは、課題なしで好きなコマンドを試せます

## 使い方

1. 上のリンクを開きます
2. 黒い端末部分をクリックして、キーボードで操作します
3. 左のミッションの問題文に従って操作し、完成形と同じ内容で保存するとクリアです

> 日本語入力（IME）はオフにして操作してください。スマートフォンでは画面下のボタンで Esc などを入力できます。

## 注意

- 本物の Vim の基本操作を再現した練習機です。Vim のすべての機能があるわけではありません
- クリア記録はブラウザの localStorage に保存されます（サーバーには送信されません）。別のブラウザや端末には引き継がれません
- 記録を消したいときは、ミッション一覧の下にある「すべての記録をリセット」を使ってください
